# Página estática

Coloque o conteúdo desta pasta na raiz do repositório publicado pelo GitHub Pages. Mantenha index.html, css/, fonts/ e images/ juntos. A página não executa JavaScript, WordPress ou Elementor. A confirmação dos termos usa validação nativa do navegador.

O checkout definido no atributo action do formulário é um serviço externo. A versão sem JavaScript não repassa os parâmetros UTM ou cookies da URL ao checkout automaticamente.
